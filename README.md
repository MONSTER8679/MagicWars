# MagicWars ⚔🪄

**إضافة Minecraft Paper** — حروب سحرية عربية بـ 11 عصا سحرية، ماندالا عملاقة، بوس، اقتصاد، ومستحضرات تجميلية.

> الإصدار: **v6.1.0** — متوافق مع **Paper 1.21.4**

## ✨ المميزات

- **11 عصا سحرية**: نار، جليد، برق، شفاء، انتقال، ريح، عدم، عاصفة، تنين، ساعة الرمال، نيزك
- **الماندالا العظمى**: خريطة 145×145 بتناظر 16 ضلعًا + زقورة سداسية + خنادق حمم وماء + 4 جزر قمرية عائمة
- **التركيب الكامل بأمر واحد**: `/mwadmin setup` — لوبي + NPCs + عالم + 6 ملاعب بضغطة واحدة
- **3 أنماط**: سولو 1v1، دوو 2v2، كواد 4v4
- **الوحش البلوري**: بوس بـ 300 صحة، ينتقم من مهاجمه، يوزع مكافآت على من شارك بقتله
- **اقتصاد كامل**: عملات + XP + متجر عصي
- **مستحضرات تجميلية**: 5 تأثيرات قتل + 5 آثار مشي
- **مكافأة يومية**: `/daily` بسلسلة متزايدة (حتى 100 💰/يوم)
- **جواهر سحرية**: تظهر بالملاعب وتمنح شفاء/طاقة/سرعة/قوة
- **القدرة القصوى**: 3 قتلات تشحن ساعة تطلق قدرة قوية

## 🚀 التركيب

### 1) البناء
```bash
# يتطلب Java 21 و Maven
mvn package
# الناتج: target/magicwars-6.1.0.jar
```

### 2) على السيرفر
1. ضع `magicwars-6.1.0.jar` في مجلد `plugins/`
2. أعد تشغيل السيرفر
3. **كمشرف**: قف بالمكان الذي تريده لوبي → `/mwadmin setup`
4. انتظر ~12 ثانية حتى رسالة "🎉 اكتمل التركيب الكامل!"
5. جرّب: `/play solo`

## 📜 الأوامر

| الأمر | الوظيفة |
|---|---|
| `/play <solo\|duo\|quad>` | الانضمام لطابور نمط |
| `/lobby` | العودة للوبي |
| `/shop` | متجر العصي |
| `/book` | كتاب السحر — كل العصي |
| `/stats` | إحصائياتك |
| `/daily` | المكافأة اليومية |
| `/killeffect list\|buy\|select\|off` | تأثيرات القتل |
| `/trail list\|buy\|select\|off` | آثار المشي |
| `/mw list` | قائمة العصي |
| `/mw give <player> <wand>` | إعطاء عصا |
| `/mwadmin setup` | **التركيب الكامل بضغطة واحدة** |
| `/mwadmin boss` | استدعاء الوحش البلوري |
| `/mwadmin setlobby / sethub` | تعيين المواقع |
| `/mwadmin genmap <mode> <count>` | توليد ملاعب |
| `/mwadmin arenas` | عرض الملاعب |

## 🗺 اللعب

- الفريقان يبدآن على **أقمار عائمة** ويعبران جسورًا زجاجية فوق الفراغ
- **خندق الحمم** (r=30..33) و**خندق الماء** (r=51..55) — الجسور الـ16 هي المعابر الآمنة
- **الزقورة المركزية** بـ 7 طبقات وسلم لولبي يصعد للقمة
- عصا الريح والعاصفة تُسقط الأعداء من الجسور ☠
